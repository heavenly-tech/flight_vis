Sideloading steps

  1. On Android, open Settings → Apps → Special access → Install unknown apps and allow your browser to install packages.
  2. Download the APK using the button above (when available) and open it to install.
  3. After install, grant location Allow all the time so fixes continue in the background.
  4. Set battery usage for the app to Unrestricted so Android does not kill tracking during flight.
  5. Copy your per-device token from the pilot profile into the app.
